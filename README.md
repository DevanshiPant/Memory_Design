# Memory Design

Verilog-based memory designs implemented and verified using simulation
and Xilinx Vivado.

## Projects

### 1. Dual-Port RAM
- Parameterized 64 × 8-bit dual-port RAM
- Independent read/write ports
- WRITE-FIRST behavior for read/write collisions
- Write collision detection
- Port-1 priority for simultaneous writes to the same address
- Verified using a dedicated testbench
- Synthesized using Xilinx Vivado


## Tools

- Verilog
- Xilinx Vivado
- EDA Playground
